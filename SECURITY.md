# Security

Please report vulnerabilities privately: on the affected repository, open **Security → Report a vulnerability**. Don't open a public issue.

We acknowledge reports within three working days and tell you what we found and when it is fixed. In scope: these SDKs and plugins, and the Seolyticize API and app at seolyticize.com. Please don't test against other customers' data, run denial-of-service tests, or use social engineering.

If you find a leaked Seolyticize API key (`sk_seo_…`) anywhere, report it the same way; we revoke it.
