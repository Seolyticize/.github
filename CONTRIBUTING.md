# Contributing

Thanks for helping. These repositories are published from Seolyticize's main codebase, so a pull request here is read, applied upstream, and comes back in the next sync — your name stays on it.

- **Bugs:** open an issue with what you called, what you expected and what came back. Include the `requestId` from any error: it finds the server's side in seconds.
- **The generated tool methods** (`_tools.py`, `tools.go`, `generated.ts`) come from the API's own registry. Don't edit them; if a tool's input looks wrong, open an issue.
- **Small, focused pull requests** with a test are the quickest to land.
- By contributing you agree your contribution is licensed under the repository's license.
